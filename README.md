# NPR Station Map

Find your closest NPR member station on an interactive map, with rings
showing the approximate FM/AM broadcast range of each station.

## DATA SOURCES AND ATTRIBUTION

Station list: NPR member station directory (organization.api.npr.org,
the service behind npr.org/stations). NPR is a trademark of National
Public Radio, Inc. This project is not affiliated with, endorsed by, or
sponsored by NPR.

Coverage estimates: derived from FCC licensed data (ERP, HAAT and station
class) published by the Federal Communications Commission via the FM
Query service. Contour radii are approximations of the licensed 60 dBu
F(50,50) service contour and are not official coverage maps.

Geocoding: Open-Meteo geocoding API (https://open-meteo.com), licensed
under CC-BY 4.0.

Basemap tiles and style: OpenFreeMap (https://openfreemap.org) with
OpenStreetMap data (c) OpenStreetMap contributors, available under the
Open Database License (ODbL).
